# Artifacts

Put what you produced along the way in this folder: plans, specs, prompts, and any skills or agent instructions (for example a `CLAUDE.md`).

You don't need to share full session logs, but this folder must show how you used AI. Don't tidy it up. Make sure you remove any secrets.

## Layout

```
artifacts/
  plans/               Implementation plans (Part 1 pipeline, Part 2 chart, etc.)
  specs/               Specs written before/while building
  decisions/           ADRs: one per judgement call
  prompts/             Prompts given to AI tools, and notes on where I stepped in
  agent-instructions/  CLAUDE.md, skills and any other agent instructions
```
