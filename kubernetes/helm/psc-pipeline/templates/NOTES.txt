The PSC pipeline is installed. It runs on "{{ .Values.schedule }}" ({{ .Values.timeZone }}) and reads {{ .Values.input.path }}.

Start a run now and follow it:

  kubectl -n {{ .Release.Namespace }} create job --from=cronjob/{{ include "psc-pipeline.fullname" . }} {{ include "psc-pipeline.fullname" . }}-manual
  kubectl -n {{ .Release.Namespace }} wait --for=condition=complete job/{{ include "psc-pipeline.fullname" . }}-manual --timeout=10m
  kubectl -n {{ .Release.Namespace }} logs job/{{ include "psc-pipeline.fullname" . }}-manual

Check the output:  helm test {{ .Release.Name }} -n {{ .Release.Namespace }}

Look up one company:

  export PGPASSWORD=$(kubectl -n {{ .Release.Namespace }} get secret {{ .Values.database.secretName }} -o jsonpath='{.data.USERDB_PASSWORD}' | base64 -d)
  kubectl -n {{ .Release.Namespace }} port-forward svc/{{ include "psc-pipeline.dbHost" . }} 5432:5432 &
  psql -h localhost -U {{ .Values.database.user }} -d {{ .Values.database.name }} -c "SELECT jsonb_pretty(payload) FROM psc.psc_by_company WHERE company_number = '04555610'"
